#   Direction

A string that indicates the direction of an axis.


### Values

Direction | Description
----------|------------
`down` | Refers to the negative-Y axis.
`up` | Refers to the positive-Y axis.
`north` | Refers to the negative-Z axis.
`south` | Refers to the positive-Z axis.
`west` | Refers to the negative-X axis.
`east` | Refers to the positive-X axis.
